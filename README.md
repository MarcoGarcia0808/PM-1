# Programacion Movil

Repositorio de trabajos y practicas de Programacion Movil.

## Proyectos incluidos

- `examen_facebook/`: ChatUPQ, app movil de mensajeria creada con Expo, React Native y TypeScript. Incluye lista de chats, contactos, pantalla de conversacion, perfil, ajustes, envio de mensajes, respuesta automatica y persistencia local con SQLite en Expo Go.
- `mi-primer-app/`: proyecto Expo usado para practicas de navegacion y actividades de clase.

## Ejecutar ChatUPQ

```powershell
cd examen_facebook
npm.cmd install --cache .\.npm-cache
npx.cmd expo start --clear
```

Para abrir en navegador:

```powershell
npx.cmd expo start --clear --web
```

Verificar TypeScript:

```powershell
npm.cmd run typecheck
```
